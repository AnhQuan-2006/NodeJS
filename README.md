1. Nội dung bài tập

Kết nối MongoDB đang chạy trên máy.

Sử dụng database qlsinhvien.

Sử dụng collection students.

Thêm ít nhất 3 sinh viên bằng insertMany().

Sử dụng find() để hiển thị danh sách sinh viên.

Đóng kết nối MongoDB sau khi hoàn thành.

2. Cài đặt module

npm.cmd install mongodb

3. Chạy chương trình

node bai04.js

4. Kết quả thực hiện

Chương trình kết nối MongoDB thành công, thêm 3 sinh viên vào collection students, sau đó sử dụng find() để hiển thị danh sách sinh viên trên Terminal và đóng kết nối.

Dữ liệu được lưu trong database qlsinhvien.

5. Hình ảnh minh họa

Chèn các ảnh chụp màn hình:

Ảnh cài đặt module MongoDB.

Ảnh chạy chương trình trên Terminal.

Ảnh danh sách sinh viên trong MongoDB Compass.

6. Kết luận

Hoàn thành bài tập thêm và hiển thị dữ liệu MongoDB bằng Node.js, sử dụng insertMany() và find() để thao tác với cơ sở dữ liệu.
