1. Mô tả bài tập

Xây dựng module tính kết quả học tập bằng Node.js.

File xulyDiem.js: Xây dựng hàm tính điểm trung bình 3 môn và hàm xếp loại học tập.

File bai06.js: Sử dụng require() để gọi module và hiển thị kết quả của 3 sinh viên.

Sử dụng module.exports để xuất các hàm.

2. Các bước thực hiện

Bước 1: Tạo thư mục Bt06.

Bước 2: Tạo file xulyDiem.js và viết các hàm tính điểm trung bình, xếp loại.

Bước 3: Tạo file bai06.js, khai báo dữ liệu 3 sinh viên và gọi module xử lý điểm.

Bước 4: Mở Terminal và chạy lệnh: "cd bai03" tiếp đến chạy lệnh: "cd Bai06" sau đó chạy lệnh: node Bai06.js
